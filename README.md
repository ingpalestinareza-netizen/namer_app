# namer_app

Primera app Flutter de Jhonny: generador de nombres con favoritos y una
pestaña Review para aprobar o rechazar propuestas, con registro auditable.

Hecha siguiendo el codelab oficial de Flutter ("Tu primera app de Flutter")
y un ejercicio propio posterior al codelab.

## App publicada

https://ingpalestinareza-netizen.github.io/namer_app/

La publica GitHub Pages en automático cada vez que se sube código a `main`
(ver `.github/workflows/deploy-pages.yml`).

## Correr en local

```sh
flutter pub get
flutter run -d chrome
```
